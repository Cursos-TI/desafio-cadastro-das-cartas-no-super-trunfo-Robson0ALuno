# Super Trunfo de Países - Cadastro de Cartas (Nível Iniciante)

Este projeto é parte de um desafio de programação para iniciantes. O objetivo é criar um sistema simples em linguagem C para cadastrar **duas cartas** do jogo Super Trunfo com o tema **Cidades de Países**.

---

## 🧠 Descrição

O programa permite ao usuário inserir, via terminal, os dados de **duas cartas**, incluindo:

- Estado (letra de A a H)
- Código da carta (ex: A01, B03)
- Nome da cidade
- População
- Área (em km²)
- PIB (em bilhões)
- Número de pontos turísticos

Após o cadastro, o programa exibe todos os dados de forma organizada na tela.

---

## 💻 Tecnologias Usadas

- Linguagem C
- Terminal / Console (entrada e saída padrão)
- Editor: GitHub Codespaces ou qualquer outro (VS Code, Code::Blocks, etc.)
